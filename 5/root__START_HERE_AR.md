# 🚀 تشغيل Dragon-R1 Full Stack - الملخص السريع

## ✨ خطوة واحدة فقط!

### على Windows:
```
1. افتح Command Prompt أو PowerShell
2. اذهب إلى المشروع:
   cd C:\Users\Hossam Galal\Desktop\RED\Cerberus\gateway

3. شغّل:
   run_fullstack.bat

4. انتظر 1-2 دقيقة...
5. فتح المتصفح: http://localhost:3000
```

### على Mac/Linux:
```
1. افتح Terminal
2. اذهب إلى المشروع:
   cd ~/Desktop/RED/Cerberus/gateway

3. شغّل:
   ./run_fullstack.sh

4. انتظر 1-2 دقيقة...
5. افتح http://localhost:3000
```

## ⚡ أداء سريع؟

```
إذا كان بطيء:

1. تحقق من الـ RAM المتاح
   Windows: Task Manager
   Mac: Activity Monitor
   Linux: top

2. أغلق البرامج الأخرى

3. استخدم SSD (أسرع من HDD)

4. تأكد من اتصال Internet جيد
```
