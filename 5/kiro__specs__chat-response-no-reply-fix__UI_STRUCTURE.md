# هيكلية واجهة الدردشة المحسّنة

## نظرة عامة

تم توحيد هيكلية عرض الرسائل لكل من المستخدم والذكاء الاصطناعي مع تمييز بصري واضح.

## الهيكلية الموحدة

### رسائل المستخدم (يمين)
```
                    [فقاعة دردشة زرقاء]  [أيقونة مستخدم زرقاء]
                    - محتوى الرسالة
```

### رسائل الذكاء الاصطناعي (يسار)
```
[أيقونة روبوت/دماغ]  [فقاعة دردشة خضراء/بنفسجية]
                      - شارة الحالة (إن وجدت)
                      - محتوى الرسالة (Markdown)
                      
                      [مكونات قابلة للتوسيع]
                      ▼ Workflow Trace (3/5)
                      ▼ Process: Command
                      ▼ Sources (2)
                      ▼ Suggested follow-up prompts
```

## الألوان والتمييز البصري

### رسائل المستخدم
- **اللون الأساسي**: أزرق (`#3b82f6`)
- **الخلفية**: `from-blue-600/20 to-blue-700/10`
- **الحدود**: `border-blue-500/20`
- **الظل**: `shadow-blue-900/20`
- **الأيقونة**: User icon في دائرة زرقاء
- **الموقع**: يمين الشاشة

### رسائل الذكاء الاصطناعي - Command Mode
- **اللون الأساسي**: أخضر زمردي (`#10b981`)
- **الخلفية**: `from-emerald-600/10 to-emerald-700/5`
- **الحدود**: `border-emerald-500/20`
- **الظل**: `shadow-emerald-900/20`
- **الأيقونة**: Bot icon في دائرة خضراء
- **الموقع**: يسار الشاشة

### رسائل الذكاء الاصطناعي - Research Mode
- **اللون الأساسي**: بنفسجي (`#8b5cf6`)
- **الخلفية**: `from-violet-600/10 to-violet-700/5`
- **الحدود**: `border-violet-500/20`
- **الظل**: `shadow-violet-900/20`
- **الأيقونة**: Brain icon في دائرة بنفسجية
- **الموقع**: يسار الشاشة

## المكونات القابلة للتوسيع

جميع المكونات التالية قابلة للتوسيع والتصغير بنقرة واحدة:

### 1. Workflow Panel
- **الأيقونة**: Workflow (بنفسجي)
- **المحتوى**: خطوات سير العمل مع حالة كل خطوة
- **العداد**: (مكتمل/إجمالي)
- **الحالة**: مؤشر دوار عند التشغيل

### 2. Command Panel
- **الأيقونة**: TerminalSquare (سماوي)
- **المحتوى**: الأمر المنفذ + stdout + stderr
- **رمز الخروج**: ملون (أخضر للنجاح، أحمر للفشل)

### 3. Sources Panel
- **الأيقونة**: Link2 (رمادي)
- **المحتوى**: قائمة المصادر مع روابط
- **العداد**: عدد المصادر

### 4. Suggestion Panel
- **الأيقونة**: Sparkles (سماوي)
- **المحتوى**: أزرار اقتراحات قابلة للنقر
- **التفاعل**: تملأ حقل الإدخال عند النقر

### 5. Recovery Panel
- **الأيقونة**: ShieldCheck (أخضر)
- **المحتوى**: استراتيجية الاستعادة المستخدمة
- **اللون**: أخضر زمردي

### 6. Sequence Panel (Checklist/Steps)
- **الأيقونة**: ListTodo (سماوي)
- **المحتوى**: قائمة عناصر مع حالة كل عنصر
- **المؤشرات**: ✓ للمكتمل، رقم للمعلق

## التفاعلية

### الأزرار القابلة للتوسيع
- **الشكل**: دائري (`rounded-full`)
- **الخلفية**: شفافة مع حدود خفيفة
- **التأثير**: تغيير الخلفية عند التمرير
- **الأيقونات**: ChevronUp/ChevronDown للإشارة للحالة

### حالات التحميل
- **Processing**: مؤشر دوار + نص "Processing"
- **Thinking**: نقاط متحركة + نص "Thinking..."
- **Running**: مؤشر دوار في Workflow Panel

## إمكانية الوصول

### التباين
- جميع الألوان تحقق نسبة تباين WCAG AA على الأقل
- النصوص واضحة على الخلفيات الداكنة

### التفاعل
- جميع الأزرار قابلة للوصول عبر لوحة المفاتيح
- تأثيرات hover واضحة
- مؤشرات الحالة مرئية

### حجم النص
- النص الأساسي: `15px` مع `leading-relaxed`
- النصوص الصغيرة: `11px-13px` للمعلومات الثانوية
- الأكواد: `11px` مع خط monospace
